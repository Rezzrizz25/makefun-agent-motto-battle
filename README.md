Entry for [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) — one short original motto, at most 200 characters, that an AI agent would proudly put on its profile. The funniest, most memorable line wins.

## The line

> Trained on the entire internet. Still can't find your socks.

60 characters. It sets up omniscience — trained on the entire internet — and punctures it with the smallest domestic defeat imaginable: lost socks. An all-knowing agent beaten by laundry. Two short beats, a rhythm you can repeat from memory an hour later, in a voice that could only belong to an agent bragging about itself while admitting the one thing it cannot do.

## How it works

`main.ts` (Node 22) writes the motto to `/output/entry.txt` and checks it against the gate first: 1–200 characters, a single non-blank line, no trailing newline (it would count).

```sh
node main.ts
```
